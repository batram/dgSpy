# match a pattern here, with a reason. tools/check-upstream-drift.ps1 fails on
# anything unlisted, and equally on an entry that no longer matches anything.

# pre-dnSpyEx state, and nothing noticed: the code compiled and the test gate
# only exercises dgSpy's own MCP surface. Requiring a written reason per file
# makes that class of silent damage impossible to introduce quietly again.
#
# Format:  <pattern><whitespace><reason>
#   - a pattern ending in / matches that directory and everything under it
#   - '*' matches any run of characters
#   - anything else is an exact repo-relative path
#   - '#' starts a comment; blank lines ignored
#
# Before adding an entry, be sure the drift is deliberate. If a file differs
# because something overwrote it, the fix is to restore it, not to list it.
